# ui-kit 组件库约定

一个文件夹 = 一个可以独立搬运的控件。整个目录拷到别的 Qt 工程里，加一行
`add_subdirectory(ui-kit/<控件名>)` 即可使用。

## 目录结构

```
ui-kit/
  <控件名>/
    CMakeLists.txt      # 编译成静态库，头文件目录 PUBLIC 导出
    <控件名>.h/.cpp     # 对外类
    README.md           # 接口、用法、依赖、限制
```

## 新增控件的步骤

1. 复制一个现有目录，改名并替换类名。
2. 在 `CMakeLists.txt` 里改静态库目标名与源文件列表。
3. 在根 `CMakeLists.txt` 的 `add_subdirectory()` 列表里加一行。
4. 在 `ui/` 的演示界面里接入，确认能编能跑。

## 约束

- **只用 Qt Widgets**，不为单个控件引入 Qt Quick、Qt Charts、QtWebEngine 等大模块依赖。
- **Qt 5.14.2 与 Qt 6.x 双版本可用**：源码里版本差异用 `QT_VERSION_CHECK` 分支，不依赖任一版本独有的 API。
- **C++17**：Qt 5.14 的头文件对 C++20/23 兼容不完整，组件库不提高标准。
- **数据与绘制分离**：原始采样点与屏幕绘制点分开管理，绘制量由像素宽度决定，不由采样量决定。
- **组件不处理鼠标交互**：缩放、平移、框选、游标、图例点击的判定全部由调用者实现；
  组件只提供范围设置、坐标换算、状态查询与变更信号。
- 每个组件对外只暴露一个主类，内部实现细节（缓冲、聚合、着色）不外泄。

## 现有组件

| 组件 | 说明 |
| --- | --- |
| `plot` | 实时曲线控件：环形缓冲 + 按像素列 min/max 聚合 + 自绘坐标轴；支持跟随/全览/任意视口、线与点样式、序号丢包断线 |
| `param-table` | 参数矩阵表格：行=参数、列=数据源（X/Y/Z 轴），列可显隐，双击编辑并校验范围，读写底层由调用者实现 |
